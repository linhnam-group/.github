# .github

Tệp mặc định dùng chung cho mọi repo của [Lĩnh Nam Group](https://github.com/linhnam-group): chính sách bảo mật, hướng dẫn đóng góp, mẫu issue và mẫu pull request. Repo nào có tệp riêng cùng tên thì tệp riêng được ưu tiên.

Shared defaults for all Lĩnh Nam Group repositories: security policy, contributing guide, issue and pull request templates. A repository's own file of the same name takes precedence.
